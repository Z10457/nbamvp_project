NBA MVP MACHINE

This is the MVP prediction machine, below are the stats and how the players rank among each other. The MVP score is a custom metric that I created to try to form a MVP winner, it takes into account various stats such as points per game, assists per game, rebounds per game, and more. The higher the MVP score, the better the player’s chances of winning the MVP award.

The 6 players ranked below are the players who had the best regular season.

Show MVP winner ages 
import pandas as pd
import plotly.express as px
from pathlib import Path

csv_path = Path('mvp_live.csv') #this cell block will be to showcase, the average age of the MVPs.
df = pd.read_csv(csv_path)


grid= px.scatter(df, x="Season", y="Age", hover_name="Player", title="MVP Winners by Age", template="plotly_dark")
grid.update_layout(
    xaxis_title="AGE",
    yaxis_title="Season",
    title="Age correlation with MVP winners",
    showlegend=False
)
order = sorted(df['Season'].unique(),key=lambda s: int(s.split('-')[0])) #this is to sort the seasons in order, since they are strings and not numbers, it will sort them by the first number in the string


grid.update_xaxes(categoryorder='array',categoryarray=order)

import numpy as np
import plotly.graph_objects as go
# Add a trendline using numpy's polyfit
df_ordered = df.copy()
df_ordered['start_year'] = df_ordered['Season'].str.split('-').str[0].astype(int)
df_ordered =df_ordered.sort_values('start_year')

connect_line = go.Scatter( #this code allows us to connect the dots in the graph with a line.
  x=df_ordered['Season'],
  y=df_ordered['Age'],
  mode='lines',
  line=dict(color='cyan',width=2),
  showlegend=False
)
grid.add_trace(connect_line )
grid.show()
