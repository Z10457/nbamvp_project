# NBA MVP Machine 🏀

An interactive NBA analytics project that analyzes player and team statistics to generate customizable MVP rankings.

## Overview

The NBA MVP Machine is a Python-based sports analytics project that combines NBA player and team data to evaluate MVP candidates. The project cleans and processes statistical data, engineers performance metrics, and calculates a weighted MVP score.

A key feature of the project is its **interactive MVP scoring system**. Users can modify the weights assigned to different statistics and generate their own MVP rankings based on the criteria they consider most important.

## Features

- 🏀 NBA player and team data analysis
- 🧹 Data cleaning and preprocessing
- 📊 Exploratory data analysis and statistical comparisons
- ⚙️ Engineered performance metrics
- 🏆 Customizable weighted MVP scoring system
- 🎛️ Interactive MVP ranking controls
- 📈 Interactive Plotly visualizations
- 🌐 Quarto web dashboard
- 🚀 Automated deployment with GitHub Actions

## How the MVP Score Works

The MVP score combines multiple player and team performance metrics using customizable weights.

Users can adjust the importance of different statistics and see how those changes affect the MVP rankings.

Example metrics include:

- Points
- Assists
- Rebounds
- Steals
- Blocks
- Turnovers
- Effective Field Goal Percentage
- Team Win Percentage

The goal is not to claim an objectively correct MVP, but to allow users to experiment with different definitions of what makes an MVP.
